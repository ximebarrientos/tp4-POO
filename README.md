# 🧠 Ejercicios de Programación Orientada a Objetos en JavaScript

Este repositorio contiene una colección de ejercicios resueltos de **POO (Programación Orientada a Objetos)** usando JavaScript. Los ejercicios están pensados para quienes están aprendiendo los conceptos básicos de objetos, clases, herencia, métodos y estructuras de control.

## 📚 Contenido

- Clases y objetos simples
- Métodos con validaciones
- Herencia entre clases (`extends`)
- Interacción con el usuario usando `prompt()` y `alert()`
- Estructuras como `for`, `if`, `switch`
- Manejo de arrays de objetos

## 🧩 Cómo usar

1. Cloná o descargá el repositorio.
2. Abrí los archivos `.js` en un editor como VS Code.
3. Ejecutá los scripts en la consola del navegador o integralos en archivos HTML.
4. Algunos ejercicios están preparados para ejecutarse directamente en el navegador usando `prompt()`.

## 🚀 Objetivo

Practicar lógica de programación y los fundamentos de POO en JavaScript de forma progresiva y práctica.
